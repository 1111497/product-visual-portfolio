# Product visual samples

Public sample portfolio for two buyer offers:

1. Label-faithful AI lifestyle product photos, 5 scenes. Packaging text, logos, and the fill line stay locked to the source pack.
2. Instagram and Snap curl-hair AR face filters.

The images are existing AI-assisted samples. This repository is not an official Amazon, Shopify, Instagram, or Snapchat product, and it is not affiliated with those companies.

The site is static: `index.html` and `styles.css` at the repository root, with images in `samples/lifestyle/` and `samples/curl-ar/`. Captions and order links are listed in `SAMPLES.md` and shown on the page.
